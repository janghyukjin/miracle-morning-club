## 📊 체크리스트 사용법

1. `checklist.html` 열기
2. 매일 완료한 작업 체크 (localStorage 자동 저장)
3. 주말에 데이터 내보내기 → 백업
4. 다른 기기에서 보려면 데이터 가져오기

### 데이터 저장 방식
- 브라우저 **localStorage** 기반
- 같은 기기/브라우저에서만 유지
- 클라우드 동기화 미지원 (수동 export/import)
