🔥 최근 활동

📝 커밋 가이드 (5분)

1
최초 1회 — repo clone
git clone https://github.com/janghyukjin/miracle-morning-club.git
cd miracle-morning-club
2
본인 폴더 만들기 (최초 1회)
mkdir -p solutions/[본인-github-username]/week-01
예: solutions/janghyukjin/week-01/
3
매일 — 풀이 파일 생성
파일명 규칙: lc-{문제번호}-{kebab-case}.{확장자}

solutions/janghyukjin/week-01/
  ├── lc-49-group-anagrams.py
  ├── lc-49-group-anagrams.md   ← 풀이 노트 (선택)
  └── lc-347-top-k-frequent.py
4
매일 — commit + push
git add solutions/[본인-username]/
git commit -m "Week 1 Day 1 - LC 49 + 347"
git push origin main
→ 잔디 칠해짐 ✅
5
commit message 추천 패턴
"Week 1 Day 1 - LC 49 + 347"
"Week 2 - Sliding Window 5문제"
"Week 3 - Median of Two Sorted Arrays Hard 풀이"
"Notes: STAR 답변 1번 작성"
→ 나중에 "내가 뭐 했지?" 찾기 쉬움
💡 매일 1 commit이면 OK — 작은 push라도 잔디 1칸 칠해집니다. 풀이가 부끄러우면 README만 push해도 됨.
